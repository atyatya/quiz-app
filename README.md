# クイズ大会アプリ

出題者1人と複数の回答者がブラウザからログインして遊べる、リアルタイムのクイズ大会Webアプリです。

## 起動

```
npm install
npm start
```

- 回答者: `http://<PCのIP>:3000/` で名前を入れて参加
- 出題者: `http://<PCのIP>:3000/host` でパスワードを入れてログイン（初期値 `admin`）
- 会場スクリーン: `http://localhost:3000/screen` をプロジェクターに映す（出題者画面の「🖥️ スクリーンを開く」からも開けます）。ダブルクリックで全画面。効果音を鳴らすには一度画面をクリックしてください

スクリーンのQRコードは自動検出したLANのIPを使います。違う場合は `$env:PUBLIC_URL="http://192.168.x.x:3000/"` で指定してください。

パスワードとポートは環境変数で変更できます（PowerShell の例）:

```
$env:HOST_PASSWORD="secret"; $env:PORT=8080; npm start
```

同じLAN内のスマホからも、起動時に表示される「LAN内」のURLで参加できます（Windowsファイアウォールの許可が必要な場合があります）。

## インターネットで遊ぶ（離れた場所の人も参加）

```
npm run online
```

または `オンラインで起動.bat` をダブルクリック。Cloudflare のトンネル機能で `https://xxxx.trycloudflare.com` のURLが発行され、どこからでも参加できます（アカウント登録・ルーター設定は不要）。

- URL は起動するたびに変わります。表示されてから **20〜30秒ほど待ってから** 共有してください（直後はまだつながらないことがあります）
- 出題者パスワードは `HOST_PASSWORD` を設定していなければ起動のたびにランダムに作られ、画面に表示されます
- スクリーンのQRコードは自動で公開URLになります
- このPCで起動している間だけ公開されます。ウィンドウを閉じる（Ctrl+C）と公開も終わります
- 出題者パスワードを5回間違えると、そのIPからは1分間ログインできなくなります。参加者は最大200人（`MAX_PLAYERS` で変更可）

注意: 早押しの順番はサーバーに届いた順で決まるため、回線の速さの差（数十〜数百ミリ秒）が影響します。

## できること

- **出題者**: 問題の作成・編集（選択式／記述式、配点、制限時間）、出題、締め切り、正解発表、判定の手動修正、得点の加減、参加者の退出、大会終了、リセット
- **回答者**: 回答、正誤の確認、リアルタイムのランキング表示
- **早押し問題**: 回答者は大きなボタン（またはスペースキー）で早押し。押した順に回答権が並び、出題者が口頭の回答を ⭕/❌ で判定。誤答の人はその問題で押せなくなり、次の人へ回答権が移る（誤答時の減点も設定可）。問題文を回答者に見せない「読み上げ式」も選べる
- **問題画像**: どの問題タイプにも画像を1枚付けられる（PNG / JPEG / GIF / WebP、10MBまで）。大きな写真は長辺1600pxに自動縮小。スクリーンでは画像を左・選択肢を右に並べて表示
- **会場スクリーン**: 待機中は参加用QRコードと参加者一覧、出題中は問題・選択肢・残り時間・回答数、正解発表では選択肢ごとの人数と正解者（速い順）、早押しでは押した順を大きく表示。出題者が「📊 ランキングを映す」でランキングに切り替え、大会終了で最終結果を表示
- 回答者は締め切りまで「回答を取り消して選び直す」ができる。そのため全員が回答しても自動では締め切らず、出題者画面に「全員回答済み」と表示される（制限時間になると自動で締め切り）
- 記述式は全角・半角・大小文字・空白の違いを無視して照合（正解はカンマ区切りで複数指定可）
- ページを再読み込みしても同じ回答者として復帰できます

問題は `questions.json`、画像は `uploads/` フォルダに保存されます（問題から外した画像ファイルは自動では消えません）。参加者と得点はサーバーのメモリ上にあるため、サーバーを再起動すると消えます。
